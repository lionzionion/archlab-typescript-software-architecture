# Como contribuir

Obrigado pelo interesse no ArchLab! Este é um repositório **educacional**.

1. Faça um fork e crie uma branch para sua alteração.
2. Instale dependências com `npm install`.
3. Rode `npm run typecheck` e `npm test`.
4. Abra um Pull Request explicando o conceito de arquitetura exercitado, o que mudou e como testar.
5. Evite incluir dados pessoais, credenciais, `.env`, `node_modules`, `dist`, arquivos JSON gerados ou modelos de IA.

Sugestões de evolução: novo adaptador de banco de dados, testes de API, casos de uso adicionais e melhoria da acessibilidade da interface.

Não redistribua PDFs protegidos, slides ou materiais exclusivos da instituição dentro deste repositório.
