## Texto sugerido para o post

Concluindo mais uma etapa da Pós-Tech em Full Stack Development! 🚀

Desta vez resolvi transformar o conteúdo de **Arquitetura de Software com TypeScript** em uma aplicação prática: o **ArchLab**.

Em vez de só estudar os conceitos separadamente, criei um laboratório de serviços de engenharia para exercitar POO, interfaces e generics, injeção de dependência, SOLID e arquiteturas Hexagonal, Onion e Clean.

Um dos pontos que mais gostei foi integrar uma **IA que roda localmente no computador**, usando **Llama 3.2 + Ollama + LangChain**. Ela recebe informações fictícias do sistema e responde pela própria interface, sem depender de API paga.

Deixei os arquivos, testes e instruções de execução para quem quiser acompanhar, adaptar ou melhorar o projeto.
