# Mensagem para o Discord / grupo da Pós-Tech

Pessoal, tudo bem? 👨‍💻

Estou compartilhando mais um projeto que desenvolvi para praticar a Pós-Tech. Desta vez é o **ArchLab**, sobre o módulo de **Arquitetura de Software com TypeScript**.

Tentei colocar os assuntos das **8 aulas** em um sistema de serviços de engenharia, para ficar mais fácil entender POO, interfaces, generics, injeção de dependência, SOLID, Hexagonal, Onion e Clean Architecture vendo o código funcionar.

**O que achei mais legal vem no final:** dá para instalar o **Ollama com Llama 3.2**, integrar com **LangChain** e **rodar uma IA local no próprio computador!** 🤖 Depois de baixar o modelo, podemos até fazer perguntas sem internet e sem pagar API.

Deixei o projeto com código, testes, guia de instalação e um passo a passo para ativar essa IA. Quem quiser, pode clonar, testar no VS Code e fazer suas modificações.

🔗 https://github.com/lionzionion/archlab-typescript-software-architecture

Não inclui os PDFs do curso, apenas o laboratório que criei para praticar.
